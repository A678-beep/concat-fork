# 剪辑功能路线图（0.2.15）

对比对象：剪映专业版 / Adobe Premiere Pro 的常用能力，按「星籁剪辑现在有没有」分四档：
**已有**（能做、有 UI 入口）、**已有-弱**（能做但入口浅/缺引导）、**缺失**、**不适用**。
优先级 P0 = 影响日常成片与转化，P1 = 常用但可绕开，P2 = 加分项。
工期是「一个人、含 UI/存盘/导出验证」的估算，不含大模型下载与云服务改造。

盘点基准：0.2.15（2026-11-20）。剪映/PR 能力项来自其公开功能说明与作者使用经验，
不逐条对应版本号。

## 二、0.2.15 实际交付的三个快赢

1. **一键踩点**（编辑菜单 › 一键踩点）：用时间轴已有的波形峰值做节拍检测，
   把跨过节拍的画面/声音片段按节拍切开；选中音频优先，没选中用播放头下的那段；
   文字/图形不切；波形没解码完会提示等一秒。
2. **3 套中文字幕样式**（内置文本预设）：字幕 · 黑底白字 / 黄字黑边 / 白字黑边，
   在「文本与字幕」样式库和字幕工具的风格下拉里直接一键套用。
3. **平台尺寸标注**（新建工程尺寸下拉）：16:9 标 B 站/YouTube 横屏，9:16 标
   抖音/视频号/快手，4:5 标小红书，选尺寸时知道给谁用。
4. （C 项，合规）**AI 生成角标**：设置 › 通用 默认打开，导出时右下角叠一枚
   「AI 生成」角标，可关。

## 三、下一步建议（按投入产出）

- **P0（下一版就做）**：打字机/逐字文字动效（拆字渲染）、字幕全文替换、
  批量套用整套样式。都是 1–3 人日、纯本地、不动架构。
- **P1**：在线模板市场（服务端已有工作台，客户端加浏览/下载/套用）、
  云端 AI 扩图、多机位同步、自定义水印。
- **P2**：嵌套序列、多轨混音路由、渐变填充花字。
- **明确不做**：本地大模型扩图/重绘（8GB 显存与 CPU 上收益太低），继续走云端。

## 四、说明

- 本清单的「已有」都指 0.2.15 实际可点可存盘的路径；「已有-弱」指能力在但入口
  或引导不足，列在 P1/P2 里做打磨。
- 工期不含测试环境的模型下载（SadTalker 插件 1.98GB 等）。
- 本文件随版本更新，不做多版本分支。
