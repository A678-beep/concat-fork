# 剪辑功能路线图（0.2.18）

对比对象：剪映专业版 / Adobe Premiere Pro 的常用能力，按「星籁剪辑现在有没有」分四档：
**已有**（能做、有 UI 入口）、**已有-弱**（能做但入口浅/缺引导）、**缺失**、**不适用**。
优先级 P0 = 影响日常成片与转化，P1 = 常用但可绕开，P2 = 加分项。
工期是「一个人、含 UI/存盘/导出验证」的估算，不含大模型下载与云服务改造。

盘点基准：0.2.18（2026-11-21）。剪映/PR 能力项来自其公开功能说明与作者使用经验，
不逐条对应版本号。0.2.17 的完整盘点保留在本文件历史里，本节只列 0.2.18 新增与变化。

## 二、0.2.18 实际交付

本版主题：**批量内容生产入口**。补上「同一个工程一次出多条平台规格成片」的能力，
把差异化的下一步（行业模板包、合规、数据回流）挂到这个入口上。

1. **一键多版本矩阵**：导出面板新增「一键多版本矩阵」开关与版本数（2–5）。
   - 五个内置配方：钩子版（抖音，剪掉开头 1.5 秒、≤15 秒、黄字黑边）、
     标准版（视频号，剪 0.5 秒、≤30 秒、原样）、完整版（B 站，不剪、≤60 秒、白字底板）、
     快剪版（快手，剪 3 秒、≤12 秒）、轻享版（小红书，剪 0.2 秒、≤20 秒）。
   - 变体只改导出用的工程副本（`retime` / `restyle` 两个纯函数），用户工程、撤销栈、
     工程文件都不动；AI 标识、自定义水印在每个变体上都生效。
   - 导出前把每版「平台 · 版本名 · 真实秒数 · 开头剪多少 · 字幕样式」列清楚；
     导出中显示「第 x/N 版 · 平台 · 阶段」并映射到总进度；可取消；完成后列出全部文件名。
   - 文件名自动：`工程名-平台-版本名-真实秒数.mp4`，例如 `宣传片-抖音-钩子版-15s.mp4`。
   - 实测（34.88 秒测试工程，3 版）：见《0.2.18 验收记录》。
2. **精准去电流声（哨音）**：把「降噪」升级为「找纯音 + 精准陷波」。
   - 自动检测：48k/8192 点 STFT，逐频点找「比邻域中位数高 ≥25dB 且持续 ≥0.5 秒」的
     窄带纯音峰，最多 4 个，给置信度。
   - 新内置效果 `concat.whistle-remove`：按检测频率开窄带 peaking EQ，强度轻/中/强
     = -12 / -26 / -40 dB；不足 4 个补 20kHz（人耳外）。
   - 音频面板「检测并去除电流声」一键完成，检查器显示频率/置信度/峰前后 dB；
     试听原声与处理后一起旁通/启用；导出走最终混音链。
   - 真实人声 + 12kHz 哨音样本：应用内检测 12000Hz / 置信度 100%，导出成片解码实测
     12kHz 峰 98.4dB → 47.0dB（衰减 51.5dB）；1-3kHz、4-8kHz 相对比例仅 -0.07/-0.46dB，
     人声未被压闷（见《0.2.18 验收记录》）。
3. 版本、文案、路线图与验收记录随包更新；本地构建，未推送。

## 三、下一步建议（按投入产出）

- **P0（0.2.19）**：行业模板包框架 + 首批 3 行业（除甲醛/家政/餐饮），模板库套用入口，
  导出前合规提示 v1；矩阵接行业配方（每种行业换自己的开头/字幕/话术）。
- **P0（0.2.20）**：广告法/绝对化用语审校；商用交付包（素材授权说明 + AI 标识 +
  平台规格 + 一页纸交付物）；矩阵变体标签写入导出记录（数据回流埋点）。
- **P1（0.3.x）**：AI 素材工厂主流程（文案→本地配音→数字人→进时间轴）、对话式精剪规则版、
  数据回流接口与「下一批建议」、行业包扩到 10+。
- **P2（0.4–1.0）**：私有化/全离线企业版（离线 License、内网模型包）、企业定制、
  多机位同步、嵌套序列。
- **明确不做**：本地大模型扩图/重绘（8GB 显存与 CPU 上收益太低），继续走云端；
  不追剪映的功能数量，按行业做深。
