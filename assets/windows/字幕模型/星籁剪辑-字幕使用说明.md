# 星籁剪辑（Concat 0.2.11 fork）· 字幕使用说明

> 适用版本：星籁剪辑 0.2.11（Windows x86_64，内置 whisper.cpp，CPU 运行）
> 实测日期：2026-11-18　实测素材：`宣传片-投资人版.mp4`（130.6 s，中文配音）

## 一、结论先说

「自动字幕」现在可用。需要的是一个 **whisper.cpp 的 GGML 多语言模型**，本机已安装：

| 项目 | 值 |
|---|---|
| 模型 | **Small (Multilingual)**，即 `ggml-small.bin` |
| 体积 | 487,601,967 B（约 488 MB / 465 MiB） |
| SHA-256 | `1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b` |
| 安装路径 | `%LOCALAPPDATA%\app.concat.editor\whisper-models\ggml-small.bin` |
| 在这台机器上 | `C:\Users\13749\AppData\Local\app.concat.editor\whisper-models\ggml-small.bin` |
| 中文支持 | 支持（whisper 的 `zh`；另有 `yue` 粤语）。实测自动识别为中文，置信度 0.997 |

> 注意：模型在 **LOCALAPPDATA**（本机数据），不在登录文件所在的 `%APPDATA%\app.concat.editor\`。这是源码规定的：`dirs.data` 在 Windows 是 `%LOCALAPPDATA%`，模型目录是 `dirs.data\whisper-models`。
>
> 便携版例外：exe 同目录若存在 `portable\` 文件夹，则配置和模型都放进 `portable\`，模型路径变为 `<安装目录>\portable\whisper-models\ggml-small.bin`。

## 三、怎么用（桌面版）

1. 打开「星籁剪辑」，打开工程并把带声音的片段放到时间线。
2. 左侧页签点 **文本与字幕** → 左栏 **字幕** → **自动字幕**。
3. 面板里：
   - **音频**：选择要转写的片段（只列时间线上有声音的片段）。
   - **模型**：`Small (Multilingual)`（未安装时会显示「未安装任何项」和下载提示）。
   - **语言**：`自动检测` 或直接选 **中文**（推荐：直接选中文可省掉自动检测的 1 分钟探测，见下）。
4. 点 **生成字幕**，等待进度条（读取声音 → 加载模型 → 正在转录）。
5. 完成后每个口语短语生成一个标题，放在画面轨道上方的第一条空轨（实测为 T3）；预览窗口可直接看到中文字幕。
6. 「导出 SRT…」把字幕轨导出为 SubRip；「导入 SRT…」可把已有字幕导入成标题。
   字幕样式（字体/颜色/描边）、位置（下/中/上）、大小（小/中/大）都在同一面板设置。

## 四、怎么安装/更换模型

### 方式 A：应用内下载（推荐，需网络）

**设置（右上齿轮 / Ctrl+,）→ 转录器 → 找到 Small (Multilingual) → 下载**。下载完成后该行左侧圆点变亮、显示「使用中」，底部显示「已安装 1 个 · 占用磁盘 488 MB」。

- 应用内下载按「设置 → 通用 → 下载项」的顺序：默认 Auto＝GitHub 镜像 → 上游 HF → hf-mirror；也可选「HF Mirror」或自定义源。
- 应用读系统代理（WinHTTP），本机系统代理是 `127.0.0.1:7897`（Clash），所以能直接下。若你的机器没开代理且 HF 访问不了，用下面的方式 B/C。
- 也可在设置页每行右侧「选择文件…」把一个已下载的 `ggml-small.bin` 交给应用（会校验 SHA-256，不符会拒绝）。

### 方式 B：一键脚本（安装目录里，带离线优先）

安装目录（或便携目录）里有：

- `安装中文语音模型.cmd` / `安装中文语音模型.ps1`

双击运行：
1. 若 `<安装目录>\模型\ggml-small.bin` 存在 → 直接复制到模型目录（离线，无需网络）；
2. 否则按 系统代理 → HuggingFace → hf-mirror → GitHub 镜像 依次下载 488 MB，校验 SHA-256 后放入模型目录；
3. 结束时提示成功或给出可手动下载的 URL。
4. 重启「星籁剪辑」生效（设置 → 转录器 应显示「已安装 1 个」）。

### 方式 C：手动放置

下载（任一）：

- `https://huggingface.co/ggerganov/whisper.cpp/resolve/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-small.bin`
- 或 `https://github.com/jub0t/Concat/releases/download/models-v1/ggml-small.bin`

放到：

```
%LOCALAPPDATA%\app.concat.editor\whisper-models\ggml-small.bin
```

文件名必须正好是 `ggml-small.bin`。放好后重启应用。**不需要**改代码或注册表。

> 没有 Small 也可以先用 **Base (Multilingual)（148 MB）**：能出中文字幕，但错字明显更多；Tiny 更差，不推荐用于中文成片。English 专用模型（`tiny.en`、`base.en`、`small.en`）不能听中文，语言下拉只会有 English。

## 五、切换语言

- 「自动字幕」面板 → **语言** 下拉：`自动检测` 或 100 种 whisper 语言（中文 = `中文`，粤语 = `粵語`）。
- 只有多语言模型能选语言；English-only 模型只能出 English，下拉被锁定。
- 选择会被记住（`%APPDATA%\app.concat.editor\settings.json` 的 `captionLanguage`；模型是 `transcriberModel`）。
- 建议：素材语言明确时直接选「中文」，比自动检测快（本机自动检测 3 段语音用了 57 秒）。

## 六、离线可用性

- 模型下载完成后，**转写全程离线**：whisper.cpp 在进程内跑，VAD 模型（silero v6.2.0）编译进 exe，不联网、不上传音频。
- 安装包 **不内置** 488 MB 模型（安装包约 107 MB）；首次使用按「方式 A/B」安装一次即可。
- 若整机无网络：从别的机器拷 `ggml-small.bin` 过来，按方式 C 放好即可。

## 七、已知限制（实测）

1. **同音字/近音词错误**：Small 模型中文识别整体可用，但专有名词和同音词会错。本次实测：`获客→货客`、`总指挥部→总指恢复`、`同城→同程`、`高意向→高义向`、`全天候→全天后`、`词库→磁库`、`堆砌→堆气`、`迁移成本→欠疑成本`、`咨询→资讯`。成片前请通读一遍字幕轨并改字。
2. **速度**：CPU 上 Small 约 **1.4× 实时**（130 s 音频约 3 分钟，含语言检测）。Base 更快、Tiny 最快但质量依次下降；本机 RX 6600 不参与 whisper（当前构建只有 CPU 路径，日志会写明「this build has no GPU path」）。
3. **标点与断句**：按语音片段切分，长句可能拆成 2–3 条；标点由模型给出，不全。
4. **尚未做的**：说话人分离（谁在说）、逐字时间码、字幕自动翻译、GPU 加速；这些上游 Concat 也还没有。
5. 自动字幕只处理**时间线上被选中/有声音的那个片段**（面板「音频」里选），不是整条时间线；多片段要逐个生成。
6. 首次生成会在 T3 轨新建 23 个文字片段；撤销（Ctrl+Z）可整体回退。

## 八、故障排查

| 现象 | 原因/处理 |
|---|---|
| 面板显示「模型：未安装任何项」 | 模型文件不在 `whisper-models` 目录，或文件名不对。按方式 B/C 放好并重启。 |
| 设置 → 转录器 里点下载失败 | 网络/代理问题。开启系统代理（Clash 等）或改用方式 B（脚本会读系统代理），或方式 C 手动放文件。 |
| 下载完成但仍显示未安装 | 检查文件名是否 `ggml-small.bin`、路径是否 `%LOCALAPPDATA%\app.concat.editor\whisper-models\`；重启应用。 |
| 生成字幕报「该片段中没有语音」/「请先在设置…」 | 片段没有声音，或模型未装好。 |
| 很慢 | 换 Base 模型，或语言直接选中文；关闭其他占用 CPU 的程序。 |
| 想彻底重来 | 设置 → 转录器 → 行尾垃圾桶图标删除模型，再重新下载。 |

日志：`%LOCALAPPDATA%\app.concat.editor\logs\concat-YYYYMMDD-HHMMSS.log`（UTC 时间）。
